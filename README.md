# Active-Directory

## Objective

This repository documents my hands-on Active Directory lab environment. The goal is to develop practical experience with Windows Server administration, identity and access management, and enterprise infrastructure by implementing and documenting real-world Active Directory scenarios.

The labs cover core administrative tasks such as domain controller deployment, user and group management, Group Policy, DNS, DHCP, and other essential Active Directory services.
